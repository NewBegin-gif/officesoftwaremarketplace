Hands-on test badges

Every tool we tested ourselves can show a badge with the facts from that test: the test date, how many of the vendor's own claims we checked and what we found for each (confirmed, contradicted, not comparable, not testable, out of date), and what our data export test did and did not cover. The badge holds no stars, scores or verdicts, because we did not measure those. A contradicted claim stays on the badge.

The rules

  • Every tested tool gets a badge, whatever the outcome. Nobody applies for it and nobody is turned down.
  • Placing it is optional. It is never paid for, never traded and never a condition for anything. The review stays the same whether you use the badge or not.
  • The image always shows the test date. When we test again, the same image updates with the new date and counts.
  • The embed code is a plain image link to the review. No script, no tracking, no hidden links.
  • Found a factual error in a review? Reply to our mail or use the correction route on the review; we fix errors and note disagreements openly.

How we test: how we review and what we tested ourselves.

Disclosure: some links on our reviews are affiliate links. We may earn a commission when you sign up, at no extra cost to you. It never changes a test result or a review.
