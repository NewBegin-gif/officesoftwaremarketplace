Is Cloudways worth it?

Managed-hosting layer that rents you servers on DigitalOcean, Vultr, Linode, AWS or Google Cloud through one dashboard, with the stack, caching, staging, cloning, backups and 24/7 platform support pre-built on top. You buy a server and put as many sites on it as it holds — no per-site plans and no visit metering — billed hourly and invoiced monthly in arrears with no contract. The trade is control: Cloudways' own documentation states there is no root access and no bring-your-own cloud account, so the server lives in Cloudways' name.
